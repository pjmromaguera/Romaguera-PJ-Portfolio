Sample Tool Notice

This is an illustrative demo tool, not a real-world assessment. The 16 locations are anonymized (Location A–P) and their elevation, rainfall, and temperature values are synthetic figures invented for demonstration only — they don't correspond to any real place. The point of this tool is to show the scoring logic and process behind this kind of suitability assessment: parameter-range overlap with a linear tolerance falloff, intentionally kept simple so the mechanics stay transparent.
